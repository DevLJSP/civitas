# Contributor Covenant Code of Conduct (Summary)

Civitas communities should be welcoming to everyone. In this repository:

- Be respectful and constructive. Critique ideas, not people.
- No harassment, hate speech, or unwelcome advances, in any channel.
- Assume good faith; ask clarifying questions before judging.
- Maintainers may remove contributions or restrict participation to enforce this.

This is a brief summary of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Full text applies. Violations can be reported privately to the maintainers.
