## Long description

**Tired of running staff elections in messy polls and DMs?**

Civitas is a free, open-source leadership system that lives inside your Discord
server. It manages the complete lifecycle of community leadership:

```
Member → Applicant → Candidate → Elected → Probation → Leader
→ term ends / resigns / removed → Succession / new election
```

**What it does:**

- 🏛️ **Positions** — Moderator, Captain, Council… with seats, terms, eligibility
- 📋 **Applications** — private modal forms, approve/reject with buttons
- 🗳️ **Real elections** — majority, approval, AND ranked-choice voting with
  proper elimination rounds, quorum checks, and anonymous mode
- 🎖️ **Mandates + probation** — winners auto-get the Discord role; trial
  periods with approve/fail/extend
- 🔄 **Succession + vacancies** — resignations and removals trigger your
  configured fallback automatically. No more leaderless teams
- ⚖️ **Impeachment, proposals, promotions, teams** — all with a full audit log

**Get started in 5 minutes:** invite Civitas, run `/tutorial`, and hold your
first election today. No dashboard to learn, no website to visit — everything
happens in Discord.

Free forever for communities. Open source (MIT):
https://github.com/DevLJSP/civitas
